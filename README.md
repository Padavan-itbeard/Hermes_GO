# Hermes

Личный учитель, который живёт в терминале. Это не чат-бот «спроси что угодно», а набор правил, памяти и инструментов поверх ИИ-агента (Codex, Claude Code или Antigravity). Вместе они превращают агента в преподавателя с характером: он ведёт тему от плана к шагам, помнит, что вы уже прошли, делает карточки для Anki и проверяет практику.

> **Из коробки Hermes настроен под курс «Go-бэкенд с нуля до джуна»** — так, как учится автор. Чтобы учить другое, его перенастраивают одним промптом: см. [PERSONALIZE.md](PERSONALIZE.md).

| Документ | Зачем читать |
|---|---|
| **README.md** (этот файл) | Поставить и запустить за 15 минут |
| [PERSONALIZE.md](PERSONALIZE.md) | Настроить под себя: цель, предмет, обращение. С готовыми промптами |
| [GUIDE.md](GUIDE.md) | Как учиться: сессия, команды, карточки, практика |
| [PHILOSOPHY.md](PHILOSOPHY.md) | Почему он устроен именно так: правила, на которых всё стоит |

## Как выглядит урок

```text
Ты:      давай разберёмся со слайсами

Hermes:  [план из 4–6 пунктов] С какого пункта начнём?

Ты:      с первого

Hermes:  Шаг 1. Что такое слайс на самом деле
         [одна идея, механизм, маленький пример кода]
         Прежде чем запускать, напиши, что выведется и почему.

Ты:      [отвечаешь своими словами]

Hermes:  [что верно, где одна неточность, как проверить] → Шаг 2 …

Ты:      делаем карточки        → карточки открываются в браузере
Ты:      /end                   → память обновлена, всё сохранено в git
```

Один шаг — одно сообщение. В конце каждого шага действуешь ты, а не учитель.

## Быстрый старт: macOS + Codex

> Система разработана и обкатана на Windows. Под macOS она подготовлена по коду (команды, скрипты запуска, открытие браузера), но на живом Mac не запускалась. Если что-то пойдёт не так — раздел [«Если не работает»](GUIDE.md#если-не-работает).

### 1. Поставь инструменты

Нужен [Homebrew](https://brew.sh). Потом в Терминале:

```bash
brew install git node python go
```

```bash
npm i -g @openai/codex
```

| Что | Зачем | Обязательно |
|---|---|---|
| Codex CLI | сам учитель | да (или Claude Code, или Antigravity) |
| Python 3.10+ | память, `/check`, `/end`, журнал тем | да |
| Node.js 20+ | Ivy — просмотр карточек в браузере | да |
| Git | сохранение прогресса | да |
| Go 1.22+ | язык курса по умолчанию | только пока курс — Go |
| Docker Desktop | PostgreSQL для практики с базой | нет, только для задач с БД |

Без Docker работает всё, кроме практики с базой данных.

### 2. Забери репозиторий

```bash
git clone https://github.com/MrHoustonOff/Hermes_OpenRepo.git hermes
```

```bash
cd hermes
```

Один раз на компьютер представься git, иначе `/end` не сможет сохранять:

```bash
git config --global user.name "Твоё имя"
```

```bash
git config --global user.email "твоя@почта"
```

### 3. Реши, где хранить прогресс

Команда `/end` коммитит твою память, карточки и решения и пушит их в `origin`. Запушить в чужой репозиторий нельзя, поэтому выбери одно:

- **Свой приватный репозиторий (советую).** Создай на GitHub пустой приватный репозиторий и перенаправь туда копию:

  ```bash
  git remote set-url origin https://github.com/<твой-логин>/<твой-репозиторий>.git
  ```

  ```bash
  git push -u origin main
  ```

- **Только локально.** Прогресс останется в git на твоём компьютере, без копии в облаке:

  ```bash
  git remote remove origin
  ```

### 4. Настрой под себя

Это шаг, без которого Hermes будет учить тебя Go и считать студентом-айтишником. Запусти Codex **в корне репозитория** (не в папке `Hermes/`):

```bash
codex
```

и вставь промпт №1 из [PERSONALIZE.md](PERSONALIZE.md#промпты), вписав свою цель. Агент сам поправит нужные файлы и прогонит проверку.

Если ты как раз хочешь учить Go-бэкенд — шаг можно пропустить: при первой встрече Hermes сам тебя расспросит и заполнит профиль.

### 5. Запусти учителя

```bash
./start_hermes_codex_bash.sh
```

Скрипт заходит в папку `Hermes/` и запускает там Codex. На вопросы о модели и режиме можно жать Enter. Первым сообщением напиши:

```text
/check
```

Hermes проверит, всё ли на месте, и скажет, чего не хватает. Увидел «ГОТОВ» — пиши, что хочешь разобрать.

## Другие системы и движки

| | Codex | Claude Code | Antigravity (`agy`) |
|---|---|---|---|
| **macOS, Linux, Git Bash** | `./start_hermes_codex_bash.sh` | `./start_hermes_claude_bash.sh` | `./start_hermes_bash.sh` |
| **Windows PowerShell** | `.\start_hermes_codex.ps1` | `.\start_hermes_claude.ps1` | `.\start_hermes.ps1` |

Можно и руками: `cd Hermes`, потом `codex`, `claude` или `agy`. Важно одно: учитель запускается **из папки `Hermes/`** — правила он берёт оттуда.

Движки можно менять хоть каждый день: правила поведения у них свои, а память общая. Начал тему на одном, закончил на другом.

## Что где лежит

```text
├─ README.md, GUIDE.md, PHILOSOPHY.md, PERSONALIZE.md   документы
├─ start_hermes*                 скрипты запуска под три движка
└─ Hermes/                       учитель запускается здесь
   ├─ AGENTS.override.md         вход для Codex
   ├─ CLAUDE.md                  вход для Claude Code
   ├─ GEMINI.md, AGENTS.md       вход для Antigravity
   ├─ rules-claude/              как учить: правила для Codex и Claude
   ├─ rules/, .agents/rules/     как учить: облегчённые правила для Gemini
   ├─ learner/                   память: profile.md, now.md, covered.md
   ├─ anki/                      карточки, по файлу на тему
   ├─ practice/                  задачи и твои решения
   ├─ log/                       журнал тем
   ├─ ivy/                       просмотр карточек в браузере
   └─ .agents/skills/            команды /check, /end, /practice
```

Твоё состояние — это `learner/`, `anki/`, `practice/` и `log/`. Всё остальное — система, и учитель её не меняет, даже если попросить.
