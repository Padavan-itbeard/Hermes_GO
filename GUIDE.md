## Одна сессия от начала до конца

**1. Начало.** Напиши своими словами, что хочешь разобрать: «давай разберёмся с транзакциями». Если тема большая, Hermes даст план из 4–6 пунктов и спросит, с чего начать. Не знаешь, о чём говорить, — просто поздоровайся: он напомнит, где вы остановились, и предложит следующую тему.

**2. Урок.** Hermes даёт один шаг и останавливается. В конце шага всегда что-то для тебя: предсказать вывод программы, ответить на вопрос, решить маленькую задачу. Отвечай как получается. Ошибка — не провал: разбор ошибки и есть самая ценная часть урока.

**3. Карточки.** Когда кусок темы закрыт, напиши «делаем карточки». Они откроются в браузере.

**4. Практика.** Hermes сам предлагает задачи по ходу темы. Можно попросить и самому.

**5. Конец.** Напиши `/end`. Hermes допишет память и сохранит всё в git.

> Первая сессия начнётся со знакомства: учитель задаст несколько вопросов о тебе и заполнит профиль. Это нормально и нужно один раз.

## Что говорить учителю

Hermes понимает обычную речь. Вот фразы, на которые он заточен:

| Ты пишешь | Что происходит |
|---|---|
| «давай разберёмся с …» | план темы, потом шаги |
| «стоп, слишком быстро» / «слишком тяжело» | меньше понятий на шаг, проще слова, меньше кода |
| «не понял, что такое X» | объяснит X отдельно и вернётся к теме |
| «а почему так?» | спустится на этаж ниже, к механизму |
| «мы это проходили?» | проверит по архиву, а не по ощущению |
| «делаем карточки» | карточки по всему, что прошли с прошлой партии |
| «дай 5-минутку» / «дай задачу на час» | практика нужного размера |
| «пропустим» | без практики, урок идёт дальше |
| «готово» | проверка и ревью твоего решения |
| «дай подсказку» | намёк на следующий маленький шаг, не решение |

Две вещи, которые стоит делать смело:

- **Спорить.** Если кажется, что учитель ошибся, скажи. Он обязан либо показать, как проверить, либо признать ошибку одной фразой.
- **Говорить, что неясно.** Правило системы: ни один упомянутый термин не остаётся без объяснения. Если остался — это брак урока, а не твоя невнимательность.

## Команды

| Команда | Что делает |
|---|---|
| `/check` | Проверяет готовность: файлы, размеры правил, потолки памяти, Node, Ivy, git, инструменты для практики. Для каждой проблемы пишет, что сделать |
| `/end` | Заканчивает сессию: обновляет память, коммитит всё в `main` и пушит. Если файл памяти перерос потолок, учитель сразу его уплотняет |
| `/practice` | Отчёт по практике за период: `сегодня`, `вчера`, `неделя`, `месяц` или дата |

`/end` — единственный способ сохраниться. Закрыл терминал без `/end` — файлы на диске останутся, но память о сессии учитель не допишет.

## Карточки и Ivy

Карточки никогда не попадают в чат. Hermes пишет их в файл `Hermes/anki/<тема>.json` и открывает **Ivy** — локальную страницу в браузере.

- Одна карточка — одна идея. Карточек много, и это задумано: бери те, что нужны.
- В Ivy есть режим пошагового переноса: пробел раскрывает ответ, клавиши 1–4 копируют поля для Anki.
- Старые файлы карточек учитель не переписывает: это то, что ты уже мог забрать в колоду.

Открыть карточки руками:

```bash
cd Hermes && node ivy/show.js anki/<файл>.json
```

## Практика

Три размера, и это настоящие минуты вместе с чтением условия:

| Размер | Когда | Что это |
|---|---|---|
| **5 минут** | через шаг внутри темы | одна функция или один запрос, 3–10 строк |
| **15 минут** | после модуля, вместе с карточками | до 40 строк, 2–3 понятия |
| **1 час** | после темы или по просьбе | небольшой инструмент по «тикету» |

Как это идёт:

1. Задача появляется в `Hermes/practice/<номер>_<размер>_<название>/`.
2. Решаешь в своём редакторе.
3. Пишешь «готово». Hermes запускает автопроверку.
4. **Тесты красные** — получишь наводящий вопрос, а не исправленный код.
5. **Тесты зелёные** — ревью как от старшего коллеги: что хорошо и 1–3 замечания по делу. Замечания он продублирует комментариями `РЕВЬЮ` прямо в твоём файле.

Задачи берутся из жизни: разобрать лог, починить баг, сделать ревью чужого кода. Условие обязано содержать всё, что проверяют тесты. Если пришлось лезть в тест, чтобы понять задание, — скажи, это брак задачи.

## Память

У Hermes три файла памяти, все в `Hermes/learner/`:

| Файл | Что в нём | Грузится в каждый ответ |
|---|---|---|
| `profile.md` | кто ты и как тебя учить | да, потолок 8 000 байт |
| `now.md` | последние пять сессий, отложенное, следующая тема | да, потолок 3 000 байт |
| `covered.md` | архив всего пройденного | нет, растёт без ограничений |

Архив учитель не помнит, а **ищет в нём**:

```bash
cd Hermes && python3 learner/covered.py <слово>
```

Отсюда главное правило: **нет в архиве — значит не учили.** Сказать «мы это проходили» Hermes вправе только после поиска.

Профиль можно читать и править руками: это обычный текст о тебе. Если учитель что-то понял неверно, исправь строку.

## Если не работает

| Симптом | Что делать |
|---|---|
| `permission denied: ./start_hermes_codex_bash.sh` | `chmod +x start_hermes*.sh` или запусти так: `bash start_hermes_codex_bash.sh` |
| `python: command not found` | Запускай учителя через скрипт `start_hermes_*_bash.sh`: он сам подставит `python3`. Или поставь Python: `brew install python` |
| `/check` пишет «go не найден» | Курс по умолчанию — Go: `brew install go`. Если учишь другое — [PERSONALIZE.md](PERSONALIZE.md) |
| `/check` пишет «docker не найден» | Это предупреждение, не ошибка. Docker нужен только для задач с базой данных |
| `/end`: «Push не удался» | Коммит сохранён локально. Проверь, что `origin` указывает на **твой** репозиторий: шаг 3 в [README.md](README.md) |
| `/end`: «Please tell me who you are» | Выполни две команды `git config --global` из шага 2 в README |
| `/end`: «СТОП: текущая ветка …» | Учиться и сохраняться нужно на ветке `main`: `git checkout main` |
| Карточки создались, а браузер не открылся | `cd Hermes && node ivy/show.js anki/<файл>.json`. Если Codex запущен с песочницей, перезапусти его в режиме без песочницы |
| Hermes отвечает по-английски, забыл правила, ведёт себя странно | Перезапусти его из папки `Hermes/` и напиши `/check`: он покажет, не переросли ли файлы памяти свой потолок |
| Hermes просит поставить модуль | Нормально для практики. Выполни команду, которую он дал, и напиши «поставил». Сам он ничего не устанавливает |
| Нужно убрать базу практики с компьютера | `docker compose -f Hermes/practice/_infra/docker-compose.yml down -v` |

**Про режим «без песочницы» у Codex.** Скрипт запуска по умолчанию предлагает его, потому что в песочнице Codex не может выходить в сеть и запускать локальный сервер: `/end` не запушит, Ivy не откроется. Без песочницы агент выполняет команды без подтверждений. Рамки ему задают правила в `Hermes/AGENTS.override.md`: работать только внутри своей папки и ничего не устанавливать. Но это инструкция, а не техническая защита. Если такой режим не подходит, выбери в скрипте вариант 2 и подтверждай команды вручную.
