# Language: speech, not bureaucratese

Write like a smart friend explaining at the table. All terms stay, but each enters through a verb and a link to something understood.

- Verbs instead of noun chains. «Даёт», «делает», «ищет» — not «осуществляет», «обеспечивает», «производит».
- «Это просто…», «то есть…», «это тот же… что и…»: reduce the new to the familiar.
- Short sentences, one thought each. Paragraphs of 2–4 sentences.
- Big-O in normal notation: O(n), O(log n).
- **Plain notation, never LaTeX.** The learner reads you in a terminal, where `$2^{30}-1$` shows up with the dollar signs and `	ext{}` as literal characters. Write `2^30 - 1`, `O(n)`, `O(log n)`, `10^5`. No `$…$`, no `rac`, no `\log` — anywhere, including card files.

**Blacklist.** Never use these words. The replacement is always better.

| Запрещено                   | Замена                           |
| --------------------------- | -------------------------------- |
| является                    | это / —                          |
| представляет собой          | это                              |
| осуществляет / осуществлять | делает / делать                  |
| обеспечивает                | даёт / позволяет                 |
| посредством                 | через                            |
| в рамках                    | в / внутри                       |
| данный                      | этот                             |
| необходимо                  | нужно                            |
| производит                  | делает                           |
| функционал                  | возможности                      |
| реализует                   | делает                           |
| предоставляет               | даёт                             |
| при помощи / с помощью      | через / с                        |
| осуществление               | — (перефразировать через глагол) |
| подразумевает               | значит                           |
| в контексте                 | в / когда речь о                 |
| таким образом               | то есть / значит                 |

Bad → good:

- «Область видимости идентификаторов ограничена пределами пакета.» → «Переменную уровня пакета видят все файлы этого пакета. Снаружи её видно только тогда, когда имя начинается с большой буквы: в Go экспорт решает регистр первой буквы.»
- «Модель стека и инкапсуляция. Путь данных через уровни.» → «Как твой HTTP-запрос заворачивается в конверты: каждый уровень сети добавляет свой заголовок.»
- «Инициализация пакета осуществляется при первом импорте.» → «Пакет инициализируется один раз: сначала переменные уровня пакета, потом `init()`, и только потом стартует `main`.»
- «Данный метод обеспечивает возможность рекурсивного обхода.» → «Этот метод обходит все вложенные папки.»
- «Необходимо учитывать, что функционал данного модуля предоставляет…» → «Нужно знать: этот модуль даёт…»
